START Quick Start

Clone all repositories:

git clone https://github.com/magos-cyber/homelab-scripts.git git clone https://github.com/magos-cyber/python-scripts.git git clone https://github.com/magos-cyber/docker-compose-stacks.git git clone https://github.com/magos-cyber/proxmox-homelab-toolkit.git git clone https://github.com/magos-cyber/sysadmin-bash-toolkit.git git clone https://github.com/magos-cyber/go-cli-tools.git

Deploy a monitoring stack:

cd docker-compose-stacks/monitoring cp .env.example .env nano .env # Edit credentials docker compose up -d

Harden a new server:

sudo bash sysadmin-bash-toolkit/scripts/bash/server-setup.sh
