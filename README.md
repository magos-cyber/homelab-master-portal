# Homelab Master Portal

Master portal for all homelab tools and scripts. A complete collection of repositories for self-hosting, automation, and infrastructure management.

## [GLOBE] Live Portal

Visit: https://magos-cyber.github.io/homelab-master-portal

## [PACKAGE] Repositories

| Repository | Description | Contents |
|------------|-------------|----------|
| [homelab-scripts](https://github.com/magos-cyber/homelab-scripts) | Bash automation & Proxmox tools | Server setup, Docker configs, security hardening |
| [python-scripts](https://github.com/magos-cyber/python-scripts) | Python stdlib scripts | 30+ scripts for monitoring, APIs, network, utilities |
| [docker-compose-stacks](https://github.com/magos-cyber/docker-compose-stacks) | Docker Compose stacks | 20+ production-ready stacks |
| [proxmox-homelab-toolkit](https://github.com/magos-cyber/proxmox-homelab-toolkit) | Proxmox VE automation | API scripts, LXC templates, backups |
| [sysadmin-bash-toolkit](https://github.com/magos-cyber/sysadmin-bash-toolkit) | Sysadmin scripts | Hardening, monitoring, VPN, backups |
| [go-cli-tools](https://github.com/magos-cyber/go-cli-tools) | Go CLI tools | Proxmox CLI, Docker manager, network diagnostics |

